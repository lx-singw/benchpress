## 📝 Devpost Project Narrative

### 💡 Inspiration
As AI engineering evolves in 2026, raw token benchmarks (like MMLU or tokens/sec on Artificial Analysis) have become virtually useless for production agent architectures. In the real world, what matters is: **How many actual dollars does it cost to fix a bug or complete a multi-step workflow?** Why pay \$10/M tokens for an entire task when an autonomous hybrid route (*Frontier Planner + Flash Coder*) cuts AI spend by 71% without sacrificing quality?

We built **Benchpress** to provide the industry's first independent, empirical economic intelligence platform for AI agents and model routing.

---

### ⚙️ What It Does
Benchpress is an end-to-end intelligence ecosystem consisting of:
1. **Autonomous Background Testing Engine:** Running on Google Cloud, continuously executing thousands of sandboxed agent trajectories across coding (SWE-Bench), financial data extraction, and multi-step API workflows.
2. **The 4 Proprietary Agentic Indices:**
   * **Cost Per Resolution (CPR) Index:** Actual dollars per verified resolved task.
   * **Hybrid Routing Pareto Matrix:** Empirical sweet spots for multi-model workflows.
   * **Tool Reliability & Retry Bloat:** Measures wasted tokens on hallucinated function calls.
   * **Context Degradation Curves:** Multi-turn decay rates from 5 to 50 turns.
3. **High-Throughput Developer API:** Providing real-time routing recommendations and verified user-facing rationales for IDEs (Cursor/Windsurf) and enterprise AI gateways.

---

### ☁️ How We Built It on the Google Cloud Stack
* **Gemini 3.5 & 3.7 Flash:** High-throughput workhorse for fast function-calling and agentic loops.
* **Gemini 2.5 Pro:** Frontier reasoning engine for complex architecture planning and code verification.
* **Google Cloud Run:** Hosts the web platform and ephemeral sandboxed evaluation workers.
* **Google Cloud Tasks:** Orchestrates asynchronous background task queues.
* **Google BigQuery:** Streams and analyzes millions of historical trajectory tokens and latency telemetry.
* **Google Cloud Firestore:** Delivers sub-millisecond leaderboard synchronization.
