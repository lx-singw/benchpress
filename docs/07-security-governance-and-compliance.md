# 07. Security, Governance & Execution-Layer Safety

## 🛡️ Security Posture & Principles

Benchpress executes untrusted, autonomous agent trajectories that interact with simulated terminal commands, file systems, and API endpoints. Maintaining an impenetrable security posture is foundational to the platform's credibility.

```
┌───────────────────────────────────────────────────────────────────────────────┐
│                           SECURITY & ISOLATION TIERS                          │
├───────────────────────────────────────────────────────────────────────────────┤
│  1. Ephemeral Sandbox Isolation: gVisor / Cloud Run isolated containers       │
│  2. Tool-Invocation Guardrails: Strict AST parameter validation               │
│  3. Network Quarantine: Zero external internet access during test runs        │
│  4. Cryptographic Audit Receipts: Immutable BigQuery telemetry logging        │
└───────────────────────────────────────────────────────────────────────────────┘
```

---

## 🔒 1. Sandboxed Execution Isolation

* **Container Isolation:** All benchmark code evaluations execute in ephemeral, sandboxed Google Cloud Run containers utilizing `gVisor` kernel-level isolation.
* **Ephemeral Lifecycles:** Sandboxes are created per trajectory run and destroyed immediately upon task termination (maximum lifetime: 300 seconds).
* **Restricted File System:** Test repositories run on isolated in-memory or ephemeral `/tmp` mount volumes with read-only system boundaries.

---

## 🛑 2. Execution-Layer Guardrails & Tool Defense

When evaluating third-party models and routing agents, Benchpress enforces runtime defense against prompt injection and destructive payloads:

1. **Static AST Analysis:** All file edits and command parameters generated by LLM tool calls are checked against a strict AST (Abstract Syntax Tree) schema prior to execution.
2. **Blocked Command Patterns:** Direct execution of destructive shell patterns (`rm -rf /`, `mkfs`, fork bombs, unauthorized credential lookups) is intercepted and logged as an adversarial failure.
3. **Quarantined Network Interface:** During execution, outbound network traffic is completely disabled; all third-party APIs (e.g., GitHub, Stripe, AWS) are served by deterministic local mock servers.

---

## 🔑 3. Secret Management & Zero-Trust Access

* **Google Cloud Secret Manager:** Model API keys and database credentials are injected at runtime via Secret Manager IAM roles. No keys or tokens are stored in source code, client bundles, or environment artifacts.
* **Role-Based Access Control (RBAC):** Public web users only have read access to aggregated leaderboard datasets; only authenticated runner services have write access to BigQuery telemetry tables.

---

## 📜 4. Cryptographic Auditability & Telemetry

* **Immutable Trajectory Logging:** Every prompt token, completion token, reasoning step, and tool invocation is recorded to BigQuery with a SHA-256 hash digest.
* **Reproducibility Guarantee:** Any enterprise client or researcher can verify a model's published score by re-running the exact seed and task payload against the open-source runner harness.
